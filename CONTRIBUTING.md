# Contributing

This repository holds the source for hnkiot.com, the website of HNK IoT Solutions (Pty) Ltd. It
is public for transparency and as a portfolio piece, not as an open-source project looking for
contributors. Pull requests from outside the team are not expected to be reviewed or merged.

That said:

- **Found a bug?** Open an [issue](https://github.com/hnkiot/hnkiot-website/issues) with steps to
  reproduce it.
- **Found a security issue?** Do not open a public issue. See [SECURITY.md](SECURITY.md) instead.
- **Want to talk about a project?** This isn't the place. Visit
  [hnkiot.com](https://hnkiot.com) or message [WhatsApp +27 61 471 9400](https://wa.me/27614719400).
